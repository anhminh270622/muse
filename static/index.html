Kết nối Muse

Kiểm tra kết nối xác nhận bạn vào được ô chat. Khi tạo xong, hãy xem lại từng clip trong project trước khi sử dụng.

Cài tiện ích kết nối một lần
  1. Trong Chrome đang đăng nhập Muse, vào chrome://extensions và bật Developer mode.
  2. Bấm Load unpacked, chọn thư mục:
  3. Giữ tab Muse đã đăng nhập trong cùng hồ sơ Chrome. Tải lại trang tool rồi bấm Kết nối trình duyệt đã đăng nhập.
Tải tiện ích ZIP

Nếu tải ZIP, giải nén rồi chọn thư mục đã giải nén. Chỉ đọc phiên trên Muse khi bạn bấm kết nối; không cần API key hoặc xuất cookie. Không mở thêm cửa sổ. Hỗ trợ cổng 8765/8766.

Gửi video qua Telegram

Tạo bot bằng @BotFather, lấy Bot Token; nhắn /start cho bot và nhập chat ID của bạn (hoặc @username của kênh/nhóm). Token được lưu riêng trên máy, không hiện lại sau khi lưu.

Chưa cấu hình

Gửi thủ công bằng nút trong từng project. Bot API hiện giới hạn video 50 MB; video lớn hơn cần nén hoặc gửi bằng bot API server riêng.
